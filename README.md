
# Student Record Management System

A beginner-friendly Student Record Management System built using Python and SQLite.

## Features

- Add new student records
- View all student records
- Search students using Student ID
- Update student details
- Delete student records
- Input validation
- Persistent database storage

## Technologies Used

- Python 3.10
- SQLite
- VS Code

## Project Structure

```text
Student-Record-Management-System/
├── main.py
├── database.py
├── student.py
├── README.md
└── .gitignore
```

## How to Run

1. Install Python 3.10 or above.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

```bash
python main.py
```

The SQLite database and students table are created automatically when the application starts.
